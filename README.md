# Test de estilos de aprendizaje

Aplicación web estática en español para explorar preferencias de aprendizaje a partir del modelo experiencial de David Kolb.

## Contenido

- `index.html`: aplicación completa (HTML, CSS y JavaScript).
- No requiere instalación de dependencias ni servidor backend.
- El logotipo está incrustado en el HTML, por lo que no hace falta cargar archivos de imagen adicionales.

## Ejecutar localmente

Abre `index.html` en un navegador moderno.

## Publicar con GitHub Pages

1. Crea un repositorio en GitHub.
2. Sube `index.html`, `README.md` y `.gitignore` a la raíz del repositorio.
3. Entra a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`; guarda los cambios.
6. GitHub Pages publicará el sitio y mostrará la URL en esa misma sección.

## Privacidad

Las respuestas se procesan en el navegador y esta versión no las envía a un servidor.
